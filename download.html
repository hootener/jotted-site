Let Claude see your jots

Jotted ships a small MCP server for Claude Code. It reads the desktop app’s jots and shows them to Claude as images. Read-only, local, no account.

git clone https://github.com/hootener/jotted-mcp.git
cd jotted-mcp && npm install
claude mcp add jotted -- node "$PWD/server.mjs"

Then, in a new Claude Code session: “look at my latest jot”, or name one, like “show me brave-gullible-snail”. Tools: list_jots, get_jot, get_latest_jot. Needs Node 22 or newer and the desktop app (browser-version jots stay in the browser). Source: github.com/hootener/jotted-mcp.

Checksums: checksums.md5 · checksums.sha256 · all releases. Verify with md5sum -c checksums.md5 or shasum -a 256 -c checksums.sha256. Your notes stay on your machine: the desktop app keeps them as plain JSON files in your user data folder, the browser version keeps them in your browser.
